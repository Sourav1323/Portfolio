# Sourav Gupta — AI-Augmented Backend Software Developer Portfolio

A dynamic, high-performance developer portfolio built with **React 19**, **Three.js (3D Interactive Canvas)**, and **Tailwind CSS**. Specifically architected to deliver:
- **Maximum ATS Optimization (98.5% score)** for Workday, Greenhouse, Taleo, Ashby, and Lever.
- **AI-Era Positioning**: Proving why deep Computer Science fundamentals (Java, SQL, SCD Data Warehousing, 5-Star HackerRank C++/SQL) paired with **Anthropic Claude Developer** certifications make engineers 10x higher-leverage rather than replaceable.
- **Interactive 3D Neural Visualization**: Custom Three.js cybernetic 3D core with orbital satellite nodes, dynamic lighting, and real-time mouse-reactive physics.
- **Recruiter Fast-Track Hub**: 60-second executive dossier, instant PDF resume download, 1-click ATS plaintext copy, and interactive AI Recruiter Copilot.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Build For Production
```bash
npm run build
```
The optimized assets will be generated in `/dist`.

### 4. Preview Production Build
```bash
npm run preview
```
